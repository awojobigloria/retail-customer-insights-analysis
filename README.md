retail-customer-insights-analysis

Project Overview:

This project analyzes sales data for a clothing company to help identify and understand top performing products, customer behavior, and growth opportunities using SQL, Python and Power BI

Business Questions:

This project analyzes retail sales data to answer the following business questions:
Which products sell best?
Which regions perform best?
Which months are strongest?
Which customers spend the most?
Which categories should we invest in?

Tools:

- SQL
- Python
- Power BI
- Excel

Project Status:

Currently in development.
